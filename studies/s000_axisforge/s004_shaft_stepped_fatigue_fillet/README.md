# stepped_fatigue_fillet

**Status:** planned.

**Question.** How sensitive is the fatigue safety factor of a stepped shaft to
the shoulder fillet radius (and the diameter ratio D/d), as computed by
AxisForge's fatigue module?

**Why.** The fillet is the cheapest design variable with the largest effect on
fatigue; it is also where the stress-concentration data the module relies on
is most exercised.

**To decide before starting.** Which standard/method the AxisForge fatigue
module implements, and its validity range for r/d and D/d.
